# `identity.exemple/` — la forme de ton identité, sans contenu

Ton identité vit dans `profil/identity/` : **privée, jamais indexée, jamais distribuée**
(BRAIN-056). Ce dossier en donne la **forme** à un brain qui démarre.

**Pour commencer** : copier ce dossier en `profil/identity/`, puis laisser le
`profile-scribe` le remplir au fil des sessions, à partir de ce que tu dis — il propose, tu
valides. Rien ne s'invente : une section vide vaut mieux qu'une section devinée.

Ce dossier-ci reste un exemple : il part avec le gabarit, ton `identity/` jamais.
